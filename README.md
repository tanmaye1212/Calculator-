# Scientific Calculator

## Description
A scientific calculator implemented in C, C++, and Python that performs basic arithmetic operations and additional mathematical functions. This project demonstrates programming fundamentals, conditional statements, switch-case logic, loops, and the use of mathematical libraries.

## Features
- Addition, subtraction, multiplication, and division
- Exponentiation (power calculation)
- Square root calculation
- Trigonometric functions: sine (`sin`), cosine (`cos`), and tangent (`tan`)
- Division-by-zero and invalid-operation handling
- Menu-driven interface for repeated calculations

## Technologies Used
- C
- C++
- Python
